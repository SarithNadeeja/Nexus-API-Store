Frequently Asked Questions

Everything you need to know about accessing and using Nexus API Store services.

An API (Application Programming Interface) is a structured way for applications to communicate with each other. Through Nexus API Store, you can access production-ready services — such as data processing, notifications, and business tools — by sending HTTP requests and receiving structured responses.
Browse the API catalog, review the documentation for the services you need, and submit an access request through our contact channels or the Request Access button on any API card. Our team will review your request and provision credentials based on your selected plan.
Usage limits are based on the number of API requests made within your billing period. Each successful request counts toward your monthly quota. Rate limits control how many requests you can make per second or minute to ensure fair access for all customers.
Yes. Depending on your access plan, you can integrate multiple API services under a single account. Pro and Business plans include access to multiple APIs with unified usage tracking through your customer dashboard.
When you approach or reach your monthly quota, you will receive notifications through your dashboard. Additional requests may be throttled or return a quota-exceeded response until the next billing period, or you can upgrade your plan for higher limits.
Access may be revoked if terms of service are violated, if abusive usage patterns are detected, or if payment obligations are not met. We follow a clear process with notification before any access restriction, except in cases of severe abuse.
